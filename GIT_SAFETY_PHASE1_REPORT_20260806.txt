 3) طرق الرجوع الآمن (Rollback Scenarios)
=======================================================
A) إلغاء كل أعمال Refactoring والعودة للحالة الحالية
   (Baseline) مع الحفاظ على إصلاحات الباص:

   git -C "C:\xampp\htdocs\alghazali" reset --hard db1c2e1

B) إلغاء كل شيء والعودة لـ Developer (علامة v1.0.0
   كما هي قبل إصلاحات الباص):

   git -C "C:\xampp\htdocs\alghazali" reset --hard 1ea2931
   أو:
   git -C "C:\xampp\htdocs\alghazali" checkout Developer

C) إلغاء الالتزام الأخير مع إبقاء التعديلات في Working
   Directory (للتصحيح السريع):

   git -C "C:\xampp\htdocs\alghazali" reset --soft HEAD~1

D) إلقاء الفرع بالكامل والعمل على Developer مباشرة:

   git -C "C:\xampp\htdocs\alghazali" checkout Developer
   git -C "C:\xampp\htdocs\alghazali" branch -D refactor-finance-service
