# نظام حجز الحافلات — منصة رحلة

هذا المستودع يحتوي على النسخة الحالية من نظام حجز الحافلات المبني باستخدام PHP وMySQL، مع واجهة عربية RTL متجاوبة ولوحة تحكم إدارية.

## بنية المشروع

يوجد التطبيق القابل للنشر داخل مجلد `infinityfree/`. يحتوي المجلد `infinityfree/database/` على مخطط قاعدة البيانات وملفات migrations اللازمة، بينما توجد اختبارات الواجهة والـAPI داخل `infinityfree/testing/`.

## الإعداد

انسخ `infinityfree/config/config.php.example` إلى `infinityfree/config/config.php` وأدخل بيانات قاعدة البيانات في بيئة التشغيل المحلية أو الاستضافة. لا تُضمّن بيانات FTP أو كلمات المرور الحقيقية داخل Git.

استورد `infinityfree/database/schema.sql` ثم طبّق ملفات migrations بالترتيب عند الحاجة. بعد ذلك شغّل التطبيق عبر PHP 8.3 أو ارفعه إلى استضافة تدعم PHP وMySQL مثل InfinityFree.

## الاختبارات

يمكن فحص JavaScript بواسطة `node --check`، وفحص PHP بواسطة `php -l`. اختبار Dashboard المحلي موجود في `infinityfree/testing/dashboard-mobile.test.mjs`، ويغطي عرض الهاتف 390×844 والبطاقات والرسوم والوضع الليلي وعدم التجاوز الأفقي.

## ملاحظات الأمان

تم استبعاد ملف الإعداد الحقيقي وأدوات FTP وملفات probe المحلية والأرشيفات من Git. استخدم متغيرات البيئة أو ملف إعداد محلي غير متتبع عند التشغيل الفعلي.
