# نظام إدارة الغزالي (Alghazali Management System)

نظام إدارة متكامل مبني باستخدام PHP و MySQL، مصمم لتسهيل إدارة العمليات المختلفة.

## لمحة عن النظام

يهدف هذا النظام إلى توفير حل شامل لإدارة العمليات اليومية، بما في ذلك على سبيل المثال لا الحصر:

-   **إدارة المعاملات المالية:** مثل فواتير المبيعات، فواتير الشراء، القيود اليومية، وإدارة الحسابات.
-   **إدارة العملاء والموردين:** تتبع بيانات العملاء والموردين، أرصدتهم، وتاريخ تعاملاتهم.
-   **إدارة الخدمات:** مثل خدمات العمرة، التأشيرات، وغيرها من الخدمات التي يقدمها النظام.
-   **التقارير:** توفير تقارير مالية وإدارية لمساعدة في اتخاذ القرارات.
-   **الأمن والصلاحيات:** نظام لإدارة المستخدمين والصلاحيات لضمان أمان البيانات.

يتميز النظام بواجهة مستخدم بسيطة وفعالة، ويدعم عمليات AJAX لتحسين تجربة المستخدم.

## متطلبات التشغيل

لتشغيل هذا النظام محليًا، ستحتاج إلى بيئة خادم ويب تدعم PHP و MySQL. يوصى باستخدام XAMPP أو WAMP Server لسهولة الإعداد.

-   **PHP:** الإصدار 7.x أو أحدث.
-   **MySQL/MariaDB:** الإصدار 5.x أو أحدث.
-   **خادم ويب:** Apache (يأتي مدمجًا مع XAMPP/WAMP).

## خطوات التثبيت

اتبع الخطوات التالية لتثبيت وتشغيل النظام على جهازك المحلي:

### 1. إعداد بيئة XAMPP

إذا لم يكن لديك XAMPP مثبتًا بالفعل:

1.  **تحميل XAMPP:** قم بتحميل XAMPP من الموقع الرسمي: [https://www.apachefriends.org/download.html](https://www.apachefriends.org/download.html)
2.  **تثبيت XAMPP:** اتبع معالج التثبيت. يفضل التثبيت في المسار الافتراضي (مثال: `C:\xampp` على Windows).
3.  **بدء تشغيل Apache و MySQL:** بعد التثبيت، افتح لوحة تحكم XAMPP (XAMPP Control Panel) وقم بتشغيل وحدتي `Apache` و `MySQL`.

### 2. استنساخ المشروع أو نسخ الملفات

1.  **استنساخ المستودع (إذا كنت تستخدم Git):**
    افتح الطرفية (Terminal/Git Bash) وانتقل إلى مجلد `htdocs` داخل تثبيت XAMPP الخاص بك (مثال: `C:\xampp\htdocs`).
    ثم قم باستنساخ المشروع:
    ```bash
    git clone https://github.com/mahumad7733/alghazali.git
    ```
    سيتم إنشاء مجلد باسم `alghazali` داخل `htdocs`.

2.  **أو نسخ الملفات يدويًا:**
    إذا قمت بتنزيل المشروع كملف مضغوط، فقم بفك ضغطه ووضع محتوياته في مجلد جديد باسم `alghazali` داخل مجلد `htdocs` الخاص بـ XAMPP (مثال: `C:\xampp\htdocs\alghazali`).

### 3. إعداد قاعدة البيانات

1.  **إنشاء قاعدة بيانات جديدة:**
    *   افتح متصفح الويب وانتقل إلى `http://localhost/phpmyadmin`.
    *   انقر على `New` في الشريط الجانبي الأيسر لإنشاء قاعدة بيانات جديدة.
    *   أدخل اسم قاعدة البيانات (مثال: `alghazali_db`) واضغط على `Create`.
2.  **استيراد ملف SQL:**
    *   حدد قاعدة البيانات التي أنشأتها للتو من الشريط الجانبي الأيسر.
    *   انقر على علامة التبويب `Import` في الأعلى.
    *   انقر على `Choose File` وابحث عن ملف قاعدة البيانات الخاص بالمشروع (قد يكون اسمه `alghazali.sql` أو ما شابهه داخل مجلد المشروع، أو `tools/alghazali.sql`).
    *   انقر على `Go` في الأسفل لاستيراد البيانات.

### 4. تهيئة اتصال قاعدة البيانات

1.  **تعديل ملف الاتصال:**
    افتح مجلد المشروع (`C:\xampp\htdocs\alghazali`) وابحث عن ملف إعدادات قاعدة البيانات (قد يكون اسمه `includes/db.php` أو `config.php` أو ما شابه ذلك).
2.  **تحديث بيانات الاعتماد:**
    قم بتعديل القيم التالية لتتناسب مع إعدادات قاعدة البيانات الخاصة بك:
    ```php
    // مثال لملف الاتصال (قد يختلف اسم الملف والمحتوى)
    define('DB_SERVER', 'localhost');
    define('DB_USERNAME', 'root'); // اسم المستخدم الافتراضي لـ XAMPP
    define('DB_PASSWORD', '');     // كلمة المرور الافتراضية لـ XAMPP (فارغة)
    define('DB_NAME', 'alghazali_db'); // اسم قاعدة البيانات الذي أنشأته
    ```
    احفظ التغييرات في الملف.

### 5. الوصول إلى النظام

بعد إكمال الخطوات السابقة:

1.  افتح متصفح الويب الخاص بك.
2.  انتقل إلى عنوان URL التالي: `http://localhost/alghazali/admin`
3.  يجب أن تظهر لك صفحة تسجيل الدخول. (اسم المستخدم وكلمة المرور الافتراضيان قد يكونان `admin/admin` أو تحقق من وثائق المشروع إن وجدت).

## هيكل المشروع (المحتوى العام)

-   `admin/`: يحتوي على ملفات لوحة التحكم والإدارة.
-   `includes/`: يحتوي على ملفات PHP المساعدة، مثل دوال الاتصال بقاعدة البيانات، الدوال المالية، ملفات الأمان، وغيرها.
-   `assets/`: يحتوي على ملفات CSS، JavaScript، الصور، وأي موارد أخرى.
-   `tools/`: قد يحتوي على أدوات مساعدة للصيانة أو التطوير.
-   `alghazali.sql`: ملف تفريغ قاعدة البيانات (أو ما يعادله).
-   ملفات PHP في الجذر: قد تحتوي على صفحات عامة أو ملفات توجيه رئيسية.
