# حزمة تطبيق رِحلة وقاعدة البيانات

هذه الحزمة تحتوي على مصدر تطبيق رِحلة PHP/ MariaDB، وملف مخطط قاعدة البيانات، وملف البيانات التجريبية، وترحيلات التطوير اللازمة لميزات العملاء والوكلاء والحجوزات والمقاعد.

## محتويات الحزمة

| المسار | المحتوى |
|---|---|
| `admin/` | صفحات لوحة التحكم |
| `api/` | واجهات API |
| `assets/` | ملفات CSS وJavaScript والصور العامة |
| `classes/` و`includes/` | المكونات والخدمات المشتركة |
| `database/` | المخطط والبيانات والترحيلات |
| `mobile/` | مصدر تطبيق Flutter المتاح في المشروع |
| `uploads/` | الصور والملفات المرفوعة اللازمة للواجهة |
| `config/config.example.php` | نموذج إعدادات دون أي بيانات حقيقية |

## خطوات التشغيل

أنشئ قاعدة MariaDB جديدة بترميز `utf8mb4`، ثم استورد `database/schema.sql` وبعده `database/seed.sql` إذا رغبت في البيانات التجريبية. بعد ذلك راجع ملفات الترحيل داخل مجلد `database/` وطبّقها بالترتيب المناسب لمخططك، خصوصًا `people_roles_migration.sql` قبل استخدام إضافة العملاء والوكلاء.

انسخ `config/config.example.php` إلى `config/config.php`، ثم ضع بيانات قاعدة البيانات الخاصة ببيئتك فقط داخل النسخة المحلية. لا ترفع `config/config.php` إلى مستودع عام أو تشاركه مع الآخرين. يجب أن يكون مجلد `config/` محميًا من الوصول العام كما هو موضح في ملف `.htaccess` الموجود في الحزمة.

شغّل التطبيق على خادم PHP يدعم PHP 8.1 أو أحدث، مع تفعيل PDO MySQL وامتداد JSON والجلسات. اجعل مجلد المشروع هو جذر الموقع، وتأكد من أن مجلد `uploads/` قابلًا للكتابة عند الحاجة، مع إبقاء ملفات PHP داخله محمية وفق إعدادات الاستضافة.

## قاعدة البيانات والإنتاج

قبل تطبيق أي ترحيل على قاعدة إنتاجية، خذ نسخة احتياطية وتحقق من أسماء الشركات والرحلات. ترحيل `backfill_broker_trip_seats.sql` يتضمن نطاقًا وقيمة افتراضية يجب مراجعتهما قبل التنفيذ، ولا ينبغي تشغيله آليًا على بيانات إنتاجية غير مفحوصة.

## الأمان

هذه النسخة لا تتضمن إعدادات الاتصال المحلية أو كلمات مرور أو ملفات نسخ احتياطية. غيّر كلمات المرور ومفاتيح الجلسات في بيئة التشغيل، ولا تحفظها داخل Git أو داخل ملفات عامة.
