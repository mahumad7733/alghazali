# مرجع نموذج لوحة الإدارة المرفق

المصدر: الملف المرفق من المستخدم `/home/ubuntu/upload/admin.html`.

يعتمد النموذج على واجهة عربية RTL بخط Tajawal وهوية أزرق داكن مع لمسة ذهبية. التكوين الرئيسي هو شريط جانبي ثابت يمين الشاشة بعرض موسع قابل للطي، وشريط علوي أبيض ثابت يحوي العنوان ومسار الصفحة والبحث ومفتاح المظهر والإشعارات وبطاقة المستخدم.

يشمل الهيكل بطاقات مؤشرات تشغيلية ذات شريط لوني جانبي وأيقونة، وجداول ذات ترويسات هادئة وحالات بشكل شارات، وأشرطة فلاتر، ونوافذ حوار، وتخطيط متجاوب يحول القائمة إلى لوحة هاتف قابلة للفتح. كما يحتوي النموذج على شجرة تنقل لمجموعات التشغيل والإدارة والتقارير والتذاكر والإشعارات، مع دعم الوضع الداكن. ستُربط هذه العناصر ببيانات لوحة الإدارة الفعلية بدل البيانات الوهمية الموجودة في الملف المرجعي.
