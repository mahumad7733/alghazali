# تحديث موقع رحلة

هذه الحزمة تحتوي على آخر تحديثات موقع حجوزات الباصات PHP/MySQL من نسخة الاختبار المحلية. وُضعت داخل مجلد مستقل لأن جذر المستودع يحتوي مشروعًا آخر، لذلك لا تستبدل ملفات المشروع الأصلي.

## المحتويات

تتضمن الحزمة تحديثات واجهة العميل ومخطط المقاعد والتذكرة ورمز QR المحلي، إضافة إلى خدمات الإدارة والمرجعيات، وترحيلات قاعدة البيانات الخاصة بمقاعد الوسيط ودور العميل وصلاحية إنشاء الحجز. كما تتضمن تقارير اختبار العميل والوكيل.

## ترتيب الدمج

يجب نسخ ملفات PHP وJavaScript وCSS إلى المسارات المطابقة داخل نسخة الموقع، ثم مراجعة إعدادات الاستضافة يدويًا وعدم استبدال ملفات `config` أو بيانات الاتصال. تُنفذ ملفات SQL بالترتيب المناسب على نسخة احتياطية من قاعدة البيانات، ولا تُنفذ على الإنتاج قبل التحقق من أسماء الجداول والنسخ الاحتياطية.

## تنبيه أمني

لا تحتوي هذه الحزمة على كلمات مرور أو مفاتيح API أو ملفات إعدادات محلية. يجب إبقاء إعدادات قاعدة البيانات وملفات البيئة خارج GitHub.

## التحقق

تم فحص صياغة PHP وJavaScript قبل إنشاء الحزمة، وتم إنشاء `MANIFEST.sha256` للتحقق من سلامة الملفات بعد النسخ.
