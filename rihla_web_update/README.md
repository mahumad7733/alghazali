# تحديث موقع حجوزات الباصات

هذه الحزمة تحتوي آخر تحديثات واجهة موقع الحجوزات المحلي، وخاصة تدفق اختيار المقاعد وفورم بيانات المسافر وتصميم تذكرة الحجز.

## محتويات التحديث

| الملف | الوظيفة |
|---|---|
| `customer.php` | ربط إصدارات الأصول الجديدة ومكتبة QR المحلية |
| `assets/js/app.js` | اختيار المقاعد، فورم بيانات المسافر، وحساب وعرض تذكرة الحجز |
| `assets/css/app.css` | تصميم المقاعد، التذكرة، الجوال، والوضع الليلي |
| `assets/js/qrcode.min.js` | مكتبة QR محلية لرسم رمز رقم الحجز |

## أهم التحسينات

بعد اختيار المقاعد ينتقل العميل إلى فورم بياناته الشخصية مباشرة. وإذا لم يكن مسجلًا، تُحفظ المدخلات قبل فتح نافذة الدخول حتى لا تضيع البيانات. كما تعرض التذكرة رقم الحجز، الشركة، المسار، الموعد، المقاعد، المسافرين، الإجمالي، حالة الطلب، ورمز QR.

تمت معالجة التخطيط المتجاوب حتى يظهر مخطط المقاعد والتذكرة بصورة مناسبة على الهاتف، مع دعم الوضع الليلي. لا تحتوي هذه الحزمة على كلمات مرور أو بيانات اتصال بقاعدة البيانات، ولم يتم تضمين أي حجز تجريبي.

## ملاحظة الدمج

أُضيفت الملفات داخل مجلد مستقل لأن جذر هذا المستودع يحتوي نظام إدارة مختلفًا ولا يحتوي أصلًا على `customer.php` أو مسارات واجهة موقع الحجوزات نفسها. يجب نسخ الملفات إلى جذر نسخة موقع الحجوزات عند النشر، مع الحفاظ على بنية مجلد `assets` الحالية.
