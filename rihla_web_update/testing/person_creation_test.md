# اختبار إنشاء العميل والوكيل — 2026-08-26

## العميل

تم فتح `admin/customers.php` محليًا بعد تسجيل دخول المدير. ظهر زر «إضافة العميل»، وفُتح النموذج في نافذة منبثقة منظمة. تم اختيار اليمن ثم مدينة تعز، وإدخال بيانات اختبارية مؤقتة، وإرسال النموذج بنجاح. عاد الجدول وأظهر سجلًا واحدًا بالحالة «قيد الانتظار» مع الاسم والبريد والهاتف والدولة والمدينة. لم يتم حذف السجل بعد، إلى حين اختبار إجراءات التفعيل والحذف.

## الوكيل

سيُختبر من صفحة الوكلاء المحلية بعد ذلك.

لا تُستخدم هذه البيانات في الإنتاج، ويجب حذف السجلين التجريبيين بعد اكتمال الاختبار.

## النتيجة النهائية

نجح إنشاء العميل التجريبي HTTP 201 وظهر في الجدول بحالة «قيد الانتظار» مع الدولة والمدينة. عند اختبار الوكيل ظهر خطأ HTTP 500 لأن الدور `agent` كان غير موجود في قاعدة الاختبار، رغم وجود صلاحية `manage_agents`. أُنشئ ترحيل `database/people_roles_migration.sql` بشكل idempotent، وطُبق محليًا؛ يضمن دوري `customer` و`agent` وربط صلاحية `create_booking` بهما. بعد التطبيق نجح إنشاء الوكيل HTTP 201، وظهر الاسم واسم المستخدم والشركة والعمولة والمحفظة في الجدول. حُذف الوكيل والعميل التجريبيان من خلال الواجهة، وعادت الصفحتان إلى صفر سجلات اختبارية.
