
## البداية

تم إنشاء حساب وكيل مؤقت مرتبط بشركة المتصدر ومحفظة صفرية للاختبار المحلي فقط. نجح فتح صفحة agent.php وفتح نموذج الدخول وتسجيل الدخول بنجاح. بعد الدخول ظهرت القائمة الجانبية وأقسام لوحة الوكيل، لكن صفحة الرئيسية عرضت «تعذر تحميل البيانات الحالية» ورسالة «لا تملك صلاحية عرض لوحة التقارير».

الحساب المؤقت والبيانات المرتبطة به سيُحذفان بعد انتهاء الاختبار.

## بعد إصلاح صلاحية لوحة المؤشرات

بعد تعديل شرط `DashboardService::overview` للسماح للوكيل برؤية مؤشرات حسابه المقيدة بـ `agent_id`، نجح تحميل لوحة الرئيسية. ظهرت مؤشرات الرحلات والمقاعد والفلاتر، مع عدم وجود حجوزات للوكيل التجريبي. فتح قسم «حجوزاتي» وظهر جدول فارغ برسالة «لا توجد حجوزات»، ولم تظهر بيانات الحجز الموجود لحساب آخر.

## الرصيد والائتمان

فتح قسم «الرصيد والائتمان» بنجاح. ظهرت محفظة YER برصيد 0 ر.ي، وحد ائتماني 0 ر.ي، ودين مستخدم 0 ر.ي، والمتاح للحجز 0 ر.ي. لم يتم تنفيذ شحن أو خصم أو أي حركة مالية.

## كشف الحساب والعمولات

فتح «كشف الحساب» بنجاح وظهر أنه لا توجد حركات مالية للوكيل التجريبي. فتح «العمولات» بنجاح وظهر أنه لا توجد عمولات بعد. كلا القسمين يعرضان حالة فارغة سليمة دون تنفيذ أي عملية مالية.

## التذاكر والوضع الليلي

فتح قسم «التذاكر» بنجاح وظهر جدول التذاكر الخاصة بالوكيل مع رسالة عدم وجود تذاكر صادرة. تم تفعيل الوضع الليلي داخل اللوحة، وتحوّلت الخلفيات والجداول والقائمة الجانبية إلى النمط الداكن مع بقاء النصوص مقروءة.

## الإشعارات

فتح زر الإشعارات بنجاح داخل لوحة الوكيل، وظهر عدد غير المقروء 0 ورسالة عدم وجود إشعارات حاليًا. تم اختبار الوضع الداكن ثم إعادته إلى الوضع الفاتح الافتراضي.

## اختبار الهاتف

على عرض 500×669 بكسل، نجح تسجيل دخول الوكيل وظهرت الصفحة الرئيسية. كانت القائمة الجانبية مغلقة أولًا ثم فُتحت بزر القائمة، وتأكد عدم وجود تمدد أفقي (`bodyScrollWidth=485`, `viewportScrollWidth=485`). كما نجح تبديل الوضع الليلي على الهاتف.

## حساب المستخدم

فتحت قائمة المستخدم بنجاح، وظهرت بيانات الاسم والبريد والهاتف وخيارا تعديل الحساب وتسجيل الخروج. فُتح نموذج تعديل بيانات الحساب وظهرت الحقول الحالية وكلمة مرور اختيارية وزر الحفظ. لم يتم تغيير أو حفظ أي بيانات.

## إنهاء الجلسة

تم إغلاق نموذج تعديل الحساب وإنهاء جلسة الوكيل بنجاح، والعودة إلى صفحة تسجيل الدخول. لم يتم حفظ أي تعديل على الحساب أثناء الاختبار.

## التنظيف النهائي

تم حذف حساب الوكيل التجريبي، وسجل الوكيل، والمحفظة، ودور الاختبار من قاعدة `rihla_attached`. التحقق النهائي: المستخدم المؤقت 0، الوكلاء 0، دور agent المؤقت 0، الحجوزات بقيت 1، والإشعارات بقيت 1. لم تُترك بيانات اختبار.

## إصلاح مطبق أثناء الاختبار

تم تعديل `includes/DashboardService.php` بحيث يسمح للوكيل بتحميل `dashboard/overview` المقيد بحجوزاته، دون منحه صلاحية التقارير العامة أو كشف بيانات مالية خارج نطاقه. فحص PHP نجح.
